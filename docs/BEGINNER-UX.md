# 初めて使う人のための画面設計

## 方針

機能数より「次に何をすればよいか」が分かることを優先します。
参加者にコマンド入力・専用エディタの操作・サーバー起動を要求しません。

## ふだんの画面

1. 動画を開く。
2. 好きな場面でコメントを書く。入力を始めると一時停止する設定が既定。
3. コメントを保存する。共有するときは専用の案内を開く。

- 最初は大きな動画選択ボタンと短い案内だけを表示。未使用の一覧・再生操作・投稿欄は隠す。
- 3ステップの進行案内は動画を開くまで表示し、その後は作業に集中できる配置にする。
- 一時停止中は動画中央に大きな「再生」ボタンを表示。
- 投稿する場面の時刻を入力欄の横に表示し、位置・大きさ・色は常に選べるようにする。
- 本文・色・文字サイズ・表示位置は日本語の入力欄と選択肢で操作。
- 一覧をカードにし、時刻ボタンでその場面へ移動、本文か「編集」で修正。一覧下に「ひとつ戻す」「やり直す」を表示。
- 削除は編集画面の確認操作から実行し、取り消せるようにする。
- タイムラインは既定では閉じ、「その他」に分ける。
- 動画出力のフレームレートやビットレートは「詳しい設定」に収納。

## なくしたもの

Vimのタブ、入力画面、ショートカット処理、エンジン、専用テスト、配信manifestの参照を削除しました。
旧設定がVim画面を指していても、通常の一覧へ移行します。既存コメントや復元データは削除しません。
通常画面のコマンド入力・生のコマンド一覧もなくしました。
入出力の互換性を保つため、読み込んだ装飾コマンドは内部では保持します。

## 共有の案内

初めに「動画で見てもらう」「コメントを渡す」「コメントを受け取る」「一緒に編集する」の4つから選びます。選んだ目的の操作だけを表示し、「選び直す」で戻れます。

- **コメントをファイルで渡す**：標準のkomenagare JSONで保存。メール等への添付は利用者が行います。
- **届いたコメントを使う**：「開く」で置き換えるか、「追加する」で今の一覧を残すかを説明。
- **コメント入りの動画を渡す**：見てもらうだけなら、コメントを重ねた動画を作る。
- **同時に編集する**：主催者からの招待リンクで参加。オンラインの部屋はこの静的ページだけでは作れないことを明示。

実際の共同編集ホストで配信されている場合だけ、参加用リンクのコピーを表示します。
参加リンクには現在のプロジェクトと共有用合言葉のみを使い、OTPやログインセッションを付けません。
OTP方式では既存のログインURLを再配布せず、管理者にだけ招待管理への入口を表示します。
リンクは参加してよい人だけに渡すよう案内し、外部へ自動送信しません。

## 確認方法

`npm test` と `npm run test:browser` を参照してください。
模擬接続先による共同編集検証であり、実komenagareサーバーは起動しません。
実際にデジタル機器に不慣れな利用者に使ってもらうユーザビリティテストは未実施です。

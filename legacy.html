使い方とファイル仕様

このHTMLを保存し、Chrome / Edge などのブラウザーで直接開いて使えます。外部ライブラリー・サーバー・通信は不要です。

01 — 動画を選んでコメントする

動画を開き、再生位置を合わせて本文を入力します。投稿時刻を固定したいときは詳細設定で指定してください。再生中の通常投稿は送信した瞬間の時刻になります。時刻欄をクリックするか本文に入力し始めると動画を一時停止するので、細かいタイミングも調整できます。

コメント一覧の時刻でシーク、鉛筆で編集、ゴミ箱で削除できます。スペースキーで再生／停止、左右キーで5秒移動（入力中・ダイアログ中は除外）。

02 — JSONで共有する

保存内容は 時刻（秒）と、装飾コマンドを含む内容だけ。UTF-8のJSONで保存します。動画本体やユーザー情報は含みません。

[
  {"time": 1.25, "content": "[naka medium white]こんにちは！"},
  {"time": 5, "content": "[ue big red]ここに注目"},
  {"time": 8.5, "content": "[shita small #66ccff]下に表示"},
  {"time": 10, "content": "[naka big speed=0.5]ゆっくり流れる"}
]

読み込んだあとに投稿した分は同じ一覧へ追加され、次の保存に含まれます。「JSONを保存」は更新版をダウンロードします。元ファイルは自動上書きしません。共有前には必ず保存してください。

複数JSONの統合は「時刻（ミリ秒に丸める）＋内容」が同一のコメントを1件にまとめます。同時刻・同一内容を意図的に複数投稿した場合も、統合時には1件になります。IDを持たないため、編集・削除の競合は自動解決できません。基本は最新版を順番に受け渡してください。同じ長さ・同じ開始位置の動画が必要です。

対応する装飾

種類 コマンド
位置 naka 流れる / ue 上 / shita 下
大きさ small / medium / big
色 white, red, pink, orange, yellow, green, cyan, blue, purple, black / 各色の2系統（red2など）/ #RRGGBB
速度・時間 speed=0.5〜speed=3 / dur=4（1〜30秒・速度より優先）
書体・装飾 font=gothic / font=mincho / font=mono / bold / thin / italic / opacity=0.5

コマンドは先頭の [ ] にスペース区切りで記述します。改行はJSON内の \n。先頭がコマンドとして認識されるテキストをそのまま表示したい場合、先頭に \ を付けます。例：\[ue]これは文字です。不明なコマンドは、ほかに有効な指定があれば無視し、すべて不明なら本文として表示します。

流れるコメントの基本寿命は4秒、上下固定は3秒です。表示サイズ・縁取り・複数行・長文の縮小・レーン配置と追い越し回避を独自実装しています。混雑時は重なります。速度・書体等の一部コマンドはこのアプリ独自の拡張です。ニコニコの特殊コマンド、コメントアートの厳密な座標互換、公式のXML形式には未対応です。

03 — コメント付き動画を書き出す

対応ブラウザーでは、動画とコメントをキャンバスに合成して、音声付きWebMとしてリアルタイム録画します。720p / 1080p・30fps、16:9（異なる縦横比は黒帯）です。MP4への直接出力ではありません。録画中はタブを前面に保ち、画面をロックしないでください。長時間・高解像度はメモリーを多く使用します。まず短い区間で確認してください。

映像はブラウザーが再生できる形式に限ります。音声は元動画の音量設定を使用します。ミュートや音量0では無音になります。書き出しの保存ファイルを実際に再生して確認してください。

保存・再現の注意

  • 通信・自動同期・同時編集・クラウド保存は行いません。
  • ブラウザーのローカル領域にコメントのみを作業復元用として自動保存します（動画は保存しません）。プライベートモードや環境によって保存できない場合があります。JSONを正式な保存先にしてください。
  • フォント・OS・絵文字による字形や幅の差は残ります。同じJSONでもピクセル単位の一致は保証できません。厳密な見た目は書き出した動画で共有してください。
  • 最大20,000件、1コメント4,000文字、JSON最大20MB。大量コメントの初期配置計算には時間がかかります。大量・長時間書き出しより区間ごとの運用を推奨します。
  • このHTML自体に動画やコメントは埋め込まれません。別の端末にもHTML・同じ動画・最新JSONを渡してください。

コメントJSONの読み込み

「統合」は既存コメントを残し、同じ時刻・同じ内容を除いて追加します。「入れ替え」は現在の一覧を置き換えます。未保存の内容は、先にJSONへ保存してください。

コメント付き動画を書き出す

動画と同じ時間をかけて録画します。このタブを前面に保ってください。音声付きWebM・30fpsで保存します。まず10秒程度のテストをおすすめします。

表示ON/OFFに関係なく、すべてのコメントを合成します。元動画が16:9以外の場合は黒帯が入ります。録画中は投稿・編集・シークを無効にします。

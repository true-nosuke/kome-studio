# KOME Studio

ローカル動画に、ニコニコ風のコメントを重ねて作成・共有するHTMLアプリです。
公式サービスやニコニコ動画の完全互換実装ではありません。

## 最初に

1. ZIPをすべて展開します。
2. `index.html` を Chrome / Edge などのブラウザーで開きます。サーバーの起動やインストールは不要です。
3. 「動画を開く」で手元の動画を選択します。
4. 再生位置を合わせてコメントを入力します。本文にフォーカスすると動画が一時停止します。
5. 「コメントする」で追加し、「JSONを保存」で更新版をダウンロードします。
6. 他の人に、このHTML・同じ動画・最新のJSONを渡します。
7. 受け取った人は動画を開き、「JSONを開く」でコメントを読み込んで続きを作れます。

同梱の `sample.comments.json` は0〜13秒付近に表示されるコメントの例です。動画自体は同梱していません。
詳細な説明・コマンド一覧はアプリ右上の「使い方」にあります。

## できること

- ブラウザーが対応するローカル動画の再生・停止・シーク・倍速・全画面表示。
- 再生時刻に同期した右→左のコメント、上固定、下固定。
- サイズ・色・縁取り・フォント・速度・表示時間・複数行。長文の自動縮小。
- 同じ表示種別内でのレーン配置と、流れるコメントの追い越し回避。混雑時や異なる表示種別間では重なります。
- コメントの編集・削除・検索、時刻クリックによる移動。
- JSONの読み込み・更新版のダウンロード・複数JSONのマージ。
- コメントのみをブラウザーのローカル領域へ作業復元用に自動保存。
- 対応環境で、元動画の音声とコメントを合成したWebM動画をリアルタイム書き出し。
- 720p / 1080p、30fps目標、区間指定、録画途中での終了・保存。
- スマートフォン幅のレイアウト、OSに連動したダークモード。

## JSON仕様

UTF-8のJSON配列です。1コメントにつき2項目だけを保存します。

```json
[
  {"time": 1.25, "content": "[naka medium white]こんにちは！"},
  {"time": 5, "content": "[ue big red]ここに注目"}
]
```

- `time`: 動画開始からの秒数。0以上の数値。読み込み・保存時にミリ秒単位に丸めます。
- `content`: 先頭に任意の装飾コマンドを含む本文。空でない文字列。改行は `\n`。
- コマンドは `[naka medium white speed=1 font=gothic]` のようにスペース区切りで記述します。
- コマンドがない場合は、白色・中サイズ・右から左へ流れる表示です。
- コマンドのような本文をそのまま表示する場合は、先頭を `\[` にします。JSON上は `"\\[ue]文字として表示"` のように記述します。
- 最大20,000件、1件4,000文字（コマンド込み）、1ファイル20MBまでです。

### コマンド

| 項目 | 指定 |
|---|---|
| 位置 | `naka`, `ue`, `shita` |
| サイズ | `small`, `medium`, `big` |
| 色 | `white`, `red`, `pink`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple`, `black`, 各色の `2` 系統、`#RRGGBB` |
| 速度 | `speed=0.25`〜`speed=3`（アプリ独自拡張） |
| 表示寿命 | `dur=1`〜`dur=30` 秒。指定時は速度より優先（独自拡張） |
| フォント | `font=gothic`, `font=mincho`, `font=mono`（独自拡張） |
| その他 | `bold`, `thin`, `italic`, `opacity=0.1`〜`opacity=1`（独自拡張） |

流れるコメントの基本寿命は4秒、上下固定は3秒。速度指定はその寿命を割ることで反映します。
不明なコマンドは、他に有効な指定があれば無視されます。すべて不明な場合は角括弧ごと本文になります。
装飾UIで作成すると、上記のコマンドを含む `content` が自動生成されます。
「本文に直接コマンドを書く」をONにすると、入力値をそのまま保存します。

## 複数人で使うとき

基本は「最新JSONを順番に受け渡す」運用です。開いたJSONに新しい投稿を足し、更新版を保存して返してください。
元のJSONは自動で上書きしません。保存時は、新しくダウンロードされるファイルを最新として扱ってください。

別々に編集したJSONは「既存の一覧に統合」でまとめられます。
時刻（ミリ秒単位）と内容が完全一致するコメントを1件にまとめます。
意図的に同時刻・同内容で複数投稿したコメントも統合時には1件になります。

IDや変更履歴を持たない最小形式のため、削除や編集の競合は解決できません。
編集前後の内容が違うコメントは別件として残ります。削除も相手の古いファイルとのマージで復活することがあります。
自動同期・通信・サーバー保存・オンライン同時編集はありません。

## 動画書き出し

1. 動画を読み込み、右上の「動画を書き出す」を選びます。
2. 開始・終了、720p/1080p、ビットレートを指定します。
3. まず10秒程度で試し、「書き出しを開始」を押します。
4. このタブを前面に保ち、画面をロックせず、実時間が経過するまで待ちます。
5. 完了後に「録画した動画を保存」を押します。

- 出力は音声付きWebM（対応するブラウザーのVP9/VP8＋Opus）です。MP4への直接出力ではありません。
- 映像は16:9。比率が異なる元動画には黒帯が入ります。文字は16:9の画面全体を使います。
- 元動画の音量を利用します。音量0・ミュートでは無音になります。
- コメント表示OFFでも、書き出しにはすべてのコメントを合成します。
- 再生速度を一時的に1倍にして録画します。完了後は元の位置・速度に戻り、一時停止します。
- 保存後は実際の動画を開いて、音声・同期・画質を確認してください。
- 30fpsは目標値であり、PC性能・動画デコード・ブラウザー負荷次第でフレーム落ちがあります。
- 長時間・高画質ではメモリーを大量に使います。5分を超える区間では警告、録画データが約600MBを超えるとそこで停止して部分保存します。
- 長い動画は区間を分割してください。

## 制限と再現性

- ニコニコの公式コメントAPI・XMLや全コマンドの互換性、特殊なコメントアートの厳密再現には対応していません。
- 同じJSONでもOSやインストール済みフォント・絵文字の違いにより文字幅・レーン配置が変わることがあります。
- 見た目を厳密に固定して共有する場合は、コメント付き動画として書き出してください。
- 開始位置・再生速度・編集内容が違う動画では、同じJSONでも同期しません。同じ動画ファイルを共有してください。
- 入力動画はブラウザーが対応するコーデックに限ります。たとえばMP4でもコーデックによっては開けません。
- 自動復元はブラウザーの保存領域に依存します。プライベートモード等では利用できない場合があります。
- 動画ファイル自体はアプリや自動復元データに保存しません。JSONを正式なバックアップにしてください。
- 単体HTMLを通常のブラウザーで直接開くことを想定しています。Notion等の埋め込みプレビューではファイル選択・ダウンロード・録画に制限がかかる場合があります。

## 動作確認

LinuxのChromiumで、ローカルHTMLとして以下を確認しました。

- 動画の読み込み・再生・停止・シーク。
- 停止中のコメント静止、シークで元の時刻に戻した際のコメント位置の一致。
- コメント編集、重複除去、JSONの保存と再読み込み、別ブラウザーコンテキストでの読み込み。
- 不正な時刻の読み込み拒否、HTMLのような本文をコードとして実行せず表示。
- 長文・複数行・基本的なレーン配置、作業データの復元。
- 元音声を含むWebM書き出し、部分録画、出力の再読み込みと有限の再生時間の認識。
- 1440pxと390px幅、読み込み・編集・書き出しダイアログ、ダーク表示。

他のOS・すべてのブラウザー・大容量ファイルでの動作を保証するものではありません。
